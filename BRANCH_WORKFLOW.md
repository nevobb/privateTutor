# Branch Workflow

- `main` is the stable base branch.
- Do not work directly on `main`.
- Every new task must use a new task-specific branch.
- PR base should be `main`.
- PR compare/head should be the task branch.
- The current feature branch `feat/nevo-tutor-mvp-9477117710285536661` was used as the initial bootstrap state.
- Do not force-push or rewrite history unless Nevo explicitly asks.
- Do not merge your own PR.
- Keep branches small and reviewable.
- If a task depends on another unmerged PR, state that dependency clearly.
