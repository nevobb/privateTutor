# Regression Smoke Playbook

## UI / composer
- Open main chat
- Send a message
- Open plus menu
- Change work mode and cost mode
- Upload from composer and confirm feedback appears in chat

## Settings
- Open Settings
- Change font size
- Change chat width
- Toggle diagnostics
- Change palette
- Go Back and confirm persistence on `/`

## Session rename / delete
- Rename a conversation
- Confirm the title updates truthfully
- Delete a conversation
- Confirm it disappears without breaking selection

## File upload / delete
- Upload a file
- Confirm processing begins and file appears
- Delete a file
- Refresh or reload file list
- Confirm deleted file stays gone

## PDF / Deep PDF
- Ask file inventory question
- Ask a grounded file question
- Check recommended/pending/completed/failed tutor behavior if relevant
- Confirm Cheap Practice does not auto-run Deep PDF

## Retrieval / inventory
- Ask “what files/questions are in the workspace?”
- Confirm no deleted file appears
- Confirm responses stay text-based and honest

## Sources
- Expand sources
- Confirm labels are readable
- Confirm no raw IDs become primary UI

## Navigation
- Move between `/` and `/settings`
- Confirm no obvious full reload stall

## Theme / palette
- Confirm palette changes apply immediately
- Confirm ThemePicker is in Settings, not the sidebar
